Base Service

This module implements the base service for handling the FAISS index and associated metadata. It includes operations for loading and saving, both locally and in Blob Storage.

class services.base_service.BaseService(index_path, metadata_path, embedder, blob_storage_service=None)

Bases: object

Responsible for managing loading, saving, and updating operations of a FAISS index and its associated metadata. Supports both local storage and Azure Blob Storage.

add_file(file_info)

Adds a file to the FAISS index. Extracts the chunks and their respective embeddings from the file information and updates the metadata.

Parameters:

file_info (dict) –

Dictionary containing file information, including:

  • file_id (str): Unique identifier for the file.

  • file_name (str): Name of the file.

  • file_extension (str): File extension.

  • raw_text (str): Full extracted text.

  • chunks (list, optional): List of text chunks.

  • chunks_embeddings (list, optional): Embedding vectors of the chunks.

load_index()

Loads the FAISS index from Blob Storage or local disk.

Returns:

The loaded FAISS index, or None if the index does not exist.

Return type:

index

load_metadata()

Loads the metadata (list) from Blob Storage or local disk.

Returns:

A list of metadata, or an empty list if the file does not exist.

Return type:

list

retrieve(query, top_k=3)

Retrieves the k most similar chunks for a given query. Generates the embedding of the query, normalizes it, and performs the search in the FAISS index.

Parameters:

  • query (str) – The text of the query.

  • top_k (int) – The number of results to be returned.

Returns:

The retrieved context with the most similar chunks.

Return type:

str

save_index_and_metadata(index, metadata)

Persists the FAISS index and the list of metadata locally and, if configured, in Blob Storage.

Parameters:

  • index – The FAISS index to be saved.

  • metadata – List of metadata to be saved.

Configuration

This module is responsible for managing the application’s configuration, loading the necessary environment variables for the proper functioning of the system.

class services.config.Config

Bases: object

Application configuration class.

This class is responsible for loading and exposing the necessary environment variables for use in the application. The variables include API keys, endpoints, and specific configurations for Blob Storage.

The configured variables are:

  • OPENAI_API_KEY: API key for accessing OpenAI.

  • OPENAI_API_ENDPOINT: Endpoint for the OpenAI API.

  • OPENAI_API_VERSION: Version of the OpenAI API.

  • DIRECTORY_PATH: Working directory path.

  • OPENAI_MODEL_NAME: Name of the OpenAI model to be used.

  • TESTE: Flag to indicate test mode.

  • MODEL_PATH: Path of the model to be used.

  • OPENAI_API_KEY_EMBEDDING_MODEL: API key for the OpenAI embedding model.

  • OPENAI_API_VERSION_EMBEDDING_MODEL: Version of the OpenAI embedding model API.

  • OPENAI_API_ENDPOINT_EMBEDDING_MODEL: Endpoint for the OpenAI embedding model API.

  • OPENAI_EMBEDDING_MODEL: Name of the OpenAI embedding model.

  • BLOB_CONNECTION_STRING: Connection string for Azure Blob Storage.

  • BLOB_CONTAINER_NAME: Name of the container in Azure Blob Storage.

  • BLOB_INDEX_BLOB: Name of the index blob in Azure Blob Storage.

  • BLOB_METADATA_BLOB: Name of the metadata blob in Azure Blob Storage.

User History Service

This module is responsible for managing the user’s interaction history. It allows loading, updating, and saving this data, both locally and via Azure Blob Storage. The functionalities include persisting the interaction history for analysis and personalizing the user experience.
