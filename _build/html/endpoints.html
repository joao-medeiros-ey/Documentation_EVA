Endpoints

This section documents the services automatically using autodoc.

Base Endpoints

This module defines the routes for updating the knowledge base and performing searches (retrieval), using the Flask application framework.

endpoints.base.retrieval()

Endpoint for performing semantic retrieval.

This endpoint receives a query via JSON and uses the BaseService to search for the k most similar chunks in the FAISS index.

Returns:

The retrieved context based on the provided query.

Return type:

JSON

endpoints.base.update_base()

Endpoint for updating the knowledge base.

This endpoint receives a file via upload, processes the content (including text extraction, chunking, and embedding generation), and updates the FAISS index, persisting the new content.

Returns:

A success message and information about the processed file, or an error message in case of failure.

Return type:

JSON

Files Endpoint

This module defines the routes for uploading and processing files, allowing for the manipulation and conversion of different file formats.

endpoints.files.upload_file()

Endpoint for file upload.

This endpoint receives a file via upload (in base64 format), processes the content, generates an explanation and embeddings, and stores the information in the global database.

Returns:

A message and information about the processed file.

Return type:

JSON

Chat Endpoint

This module defines the endpoint for chat interaction, using the Large Language Model (LLM) and the context retrieval index, allowing communication and obtaining responses based on user queries.

endpoints.chat.chat()

Endpoint for chat.

This endpoint receives a user query, performs context retrieval using FAISS, and invokes the Large Language Model (LLM) to generate a response based on the context.

Returns:

The retrieved context and the response generated by the chat.

Return type:

JSON

Skills Endpoint

This module defines the endpoint for executing specific skills, combining context retrieval, response generation, and user history management.

endpoints.skills.skill()

Endpoint for executing skills.

This endpoint receives a query and parameters related to the desired skill, performs context retrieval, generates a specific response using the Large Language Model (LLM), and updates the user history, if applicable.

Returns:

The processed skill, the retrieved context, and the generated response.

Return type:

JSON

Documents Endpoint

This module defines the route for listing the documents used in the knowledge base. It provides functionalities to access and manage the available documents, facilitating the querying and organization of information.

endpoints.documents.list_documents()

Endpoint that returns the names (file_name) of the documents present in the metadata file.

This endpoint extracts the unique names of the documents, considering that each file may have multiple chunks and, consequently, multiple metadata entries.

Returns:

A JSON object containing a list of document names and the total number of documents found.

Return type:

Json
