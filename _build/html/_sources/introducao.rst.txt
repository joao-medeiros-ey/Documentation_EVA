Introduction
==========

This project aims to integrate an API developed with Flask, along with specialized services for file processing and embedding extraction.
To achieve this, we utilize advanced technologies, including FAISS, SentenceTransformer, and Azure OpenAI, as well as an interactive interface built with Streamlit.

Below, we present the main features of the system:

- **File Processing:** The system is capable of processing various file formats, including PDF, Excel, DOC, etc.


- **Semantic Database Management:** We have implemented a mechanism for updating and managing a semantic database using a FAISS index.

- **Integration with Language Models:** The project includes integration with Large Language Models (LLM), enabling real-time response generation in a chat environment, as well as the implementation of specific skills.

- **Metadata Storage:** The metadata generated during processing is securely stored in Azure Blob Storage.
