Módulos

Serviços

Base Service

Módulo: base_service Implementa o serviço base para manipulação do índice FAISS e metadados, incluindo operações de carregamento e salvamento local ou em Blob Storage.

class services.base_service.BaseService(index_path, metadata_path, embedder, blob_storage_service=None)

Base: object

Classe BaseService.

Responsável por gerenciar operações de carregamento, salvamento e atualização de um índice FAISS e seus metadados associados, suportando tanto armazenamento local quanto via Azure Blob Storage.

add_file(file_info)

Adiciona um arquivo ao índice FAISS. Extrai chunks e os seus respectivos embeddings a partir das informações do arquivo e atualiza os metadados.

Parâmetros:
file_info (dict): Dicionário com informações do arquivo, incluindo:

  • file_id: Identificador único do arquivo.

  • file_name: Nome do arquivo.

  • file_extension: Extensão do arquivo.

  • raw_text: Texto completo extraído.

  • chunks (opcional): Lista de pedaços de texto.

  • chunks_embeddings (opcional): Vetores de embedding dos chunks.

load_index()

Carrega o índice FAISS a partir do Blob Storage ou do disco local.

Retorna:

index: O índice FAISS carregado ou None se não existir.

load_metadata()

Carrega os metadados (lista) a partir do Blob Storage ou disco local.

Retorna:

list: Lista de metadados ou lista vazia se o arquivo não existir.

retrieve(query, top_k=3)

Recupera os k chunks mais similares para uma query fornecida. Gera o embedding da query, normaliza e realiza a busca no índice FAISS.

Parâmetros:

query (str): Texto da consulta. top_k (int): Número de resultados a serem retornados.

Retorna:

str: Contexto recuperado com os chunks mais similares.

save_index_and_metadata(index, metadata)

Persiste o índice FAISS e a lista de metadados localmente e, se configurado, no Blob Storage.

Parâmetros:

index: O índice FAISS a ser salvo. metadata: Lista de metadados a ser salva.

Classe BlobStorageService.

Fornece métodos para operações com o Azure Blob Storage, incluindo download, upload e verificação da existência de blobs.

blob_exists(blob_name)

Verifica se um blob com o nome especificado existe no container.

Tipo de retorno:

bool

Parâmetros:

Retorna:

Retorna:

upload_file_to_blob(file_path, blob_name)

Envia um arquivo para o Azure Blob Storage, sobrescrevendo se já existir.

file_path (str): Caminho do arquivo local a ser enviado. blob_name (str): Nome do blob no armazenamento.

LLM Service

Módulo: llm_service Fornece funcionalidades para integração com LLM, incluindo geração de explicações, respostas de chat e respostas para skills específicas.

Base: object

Classe LLMService.

Interage com o modelo LLM para gerar explicações e respostas baseadas em prompts e contexto fornecido.

chat_response(user_query, context, temperature=0.7, top_p=0.85)

Gera uma resposta de chat utilizando o contexto recuperado da base.

Parâmetros:

user_query (str): Pergunta do usuário. context (str): Contexto recuperado do índice FAISS. temperature (float): Parâmetro de temperatura para o LLM. top_p (float): Parâmetro top_p para o LLM.

Gera uma explicação resumida para o documento fornecido.

document_text (str): Texto do documento. file_name (str): Nome do arquivo. file_extension (str): Extensão do arquivo.

Retorna:

skill (str): Nome da skill. query (str): Consulta do usuário. retrieved_context (str): Contexto recuperado. temperature (float): Parâmetro de temperatura para o LLM. top_p (float): Parâmetro top_p para o LLM. user_history (list): Histórico de interações do usuário (opcional).

Retorna:

str: Resposta gerada para a skill.

Endpoints

Base Endpoints

Módulo: base endpoint Define as rotas para atualização da base de conhecimento e realização de buscas (retrieval), utilizando a estrutura da aplicação Flask.

endpoints.base.retrieval()

Endpoint para realizar a recuperação semântica.

Recebe uma query (consulta) via JSON e utiliza o serviço BaseService para buscar os k chunks mais similares no índice FAISS.

Retorna:

JSON contendo o contexto recuperado.

endpoints.base.update_base()

Endpoint para atualização da base de conhecimento.

Recebe um arquivo via upload, processa o conteúdo (extração de texto, chunking, geração de embeddings) e atualiza o índice FAISS, persistindo o novo conteúdo.

Retorna:

JSON com mensagem de sucesso e informações do arquivo processado, ou erro em caso de falha.

Files Endpoints

Módulo: files endpoint Define as rotas para upload e processamento de arquivos.

endpoints.files.upload_file()

Endpoint para upload de arquivos.

Recebe um arquivo via upload, processa o conteúdo, gera explicação e embeddings, e armazena as informações na base global (exemplo demonstrativo).

Retorna:

JSON com mensagem e informações do arquivo processado.

Chat Endpoints

Módulo: chat endpoint Define o endpoint para interação de chat, utilizando o LLM e o índice de recuperação de contexto.

endpoints.chat.chat()

Endpoint para chat.

Recebe uma query do usuário, realiza a recuperação de contexto usando FAISS, e invoca o LLM para gerar uma resposta com base no contexto.

Retorna:

JSON contendo o contexto recuperado e a resposta do chat.

Skills Endpoints

Módulo: skills endpoint Define o endpoint para execução de skills específicas, combinando recuperação de contexto, geração de resposta e gerenciamento de histórico do usuário.

endpoints.skills.skill()

Endpoint para execução de skills.

Recebe uma query e parâmetros relacionados à skill desejada, realiza a recuperação do contexto, gera a resposta específica utilizando o LLM, e atualiza o histórico do usuário se aplicável.

Retorna:

JSON com a skill processada, contexto recuperado e resposta gerada.
