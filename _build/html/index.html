Index of API

Entry point of the Flask application. Configures and initializes components, services, and routes.

main.create_app()

Creates and configures the Flask application.

This function initializes the services, configures Blob Storage (if enabled) and registers the necessary blueprints for the application.

Returns:

The configured Flask application instance.

Return type:

app
